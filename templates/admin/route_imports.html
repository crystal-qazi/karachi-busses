Import routes, directions and stops

Bulk import a route network from CSV. Imported routes remain drafts and imported stops remain under review. No route is published automatically.

CSV format

One row per stop in its route direction. Use the same route_code and direction_name for rows belonging to the same direction.

ColumnRequiredExample / purpose
route_codeYesR-01
route_nameYesKorangi to Tower
operator_nameNoOperator name
direction_nameYesOutbound / Inbound
start_label, end_labelNoTerminal labels (consistent per direction)
stop_nameYesNamed boarding stop
latitude, longitudeYesWGS84 decimal coordinates
stop_sequenceYes1, 2, 3…
addressNoRoad / landmark

Maximum 5,000 stop rows per import. Each direction needs at least two stops. GeoJSON shapes are added separately in the direction map editor.
