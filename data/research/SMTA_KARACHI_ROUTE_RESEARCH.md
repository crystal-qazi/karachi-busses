# Karachi bus-route research register — draft only

**Purpose:** collect source material for human verification. This file is research evidence, not approved operational data.
**Database status:** NOT IMPORTED. No database records are created or changed by this research file.
**Primary source:** Sindh Mass Transit Authority (SMTA), Karachi Route Map and Provincial Route Directory: https://smta.gos.pk/route-map
**Map reference:** Think Transportation, KHI-MAP-08, dated 2025-01-01: https://thinktransportation.net/Karachi_transport_map_peoples_bus_service_green_line_orange_line_think_transportation.pdf
**Accessed:** 2026-11-16

## Source caveats
- SMTA's route map index is a map summary and explicitly says it does not authenticate third-party service data shown on the map.
- The SMTA route directory supplies textual route descriptions and active/inactive labels. Treat those as source statements, not independently field-verified operations.
- Place-name spellings are retained close to source wording; variants are not silently merged.
- Via lists are source-described areas/stops, not guaranteed every formal bus stop.
- Distances are published route distances, not recalculated road distances.
- No GPS coordinates, boarding-side distinctions, stop IDs, road-centreline geometry, timetable, fares, or live service status are inferred here.
- BRT Green and Orange are shown on the map index but their detailed station sequences are not transcribed in the route directory section below; collect from their dedicated official sources in a separate pass.

## Conflicts and verification queue

1. **R1 terminal variation:** map index says Khokhrapar; route directory says Khokharapar 04. Think Transportation's older article has Model Colony as the route origin. Confirm terminal and whether route variants/branching exist.
2. **R2 endpoint variation:** map index says Indus Hospital; SMTA directory says Korangi Crossing, with Indus Hospital as an intermediate location. Think Transportation source uses Indus Hospital as endpoint. Confirm current alignment and direction.
3. **R3 alignment variation:** SMTA directory gives North Karachi to Nasir Jump; other published descriptions have temporary alignments and different intermediate locations. Confirm latest approved path.
4. **R4 endpoint variation:** map index says Powerhouse; directory says North Karachi. Confirm actual terminal.
5. **R8 direction label:** map index says Tower–Yousuf Goth; directory says Yousuf Goth–Tower. This may be direction presentation rather than a different route.
6. **R11 endpoints:** map index says Miran Naka–Shireen Jinnah Colony; directory says Mera Naka–Ziauddin Hospital.
7. **R12 endpoints:** map index says Naddi Kinara–Lucky Star; directory says Memon Goth–Sadar Lucky Star.
8. **R13 order:** directory's via list begins with Gulbai before Hawksbay, then returns to Gulbai. Verify direction and any repeated/loop segment.
9. **R5–R7:** explicitly marked inactive by SMTA directory; do not present as currently operating without newer evidence.
10. **EV distances:** directory values (41/44/23/58/48 km) differ substantially from older secondary-source summaries; use SMTA values as the current source statement, pending field/official confirmation.
11. **Route numbering:** map index lists R1–R13 plus DD01 and EV1–EV5; SMTA detailed directory additionally includes Route 14, producing 20 Karachi entries (14 PBS/Pink + 5 EV + 1 DD).
12. **Spelling normalization:** Sorab/Sohrab, Khokharapar/Khokrapar, Kemari/Keamari, Lalukhait/Liaquatabad, Nasir/Nasir Jump, Maripur/Mauripur and other variants need a canonical alias table after review.
