## Extraction policy
- Preserve route code exactly as printed, including suffixes and punctuation.
- Every occurrence of a repeated route code is a separate variant.
- Preserve the printed stop order; do not infer reverse direction.
- Retain original spelling and add normalized aliases only in a separate review step.
- Capture PDF page number for every route. If page attribution cannot be confirmed from extracted text, mark it "page verification required".
- Distinguish formal stops from landmarks, institutions, markets, roads and neighbourhoods.
- Never infer current operating status, operator, fare, frequency, coordinates or road geometry from this 2010 source.
- Verify OCR and spelling against the original page image before approving a record.

## Source-level findings
The document contains a broad directory of numbered minibuses, coaches and route variants, including codes such as 1-A, 1-C, 1-H, 4-S, 10, 11-A, 11-C, 16-F, 17-J, 18-K, 50-C, A-25, D-19, F-10 and F-16, plus named coach services. Some codes appear more than once with differing alignments. These must remain distinct variants pending review.

## Known QA issues

2. Duplicate codes including 16-F, 17-J, 18-K and other repeated identifiers need independent variant records.
3. OCR and transliteration may produce misspellings, line-wrap errors or missing separators.
4. Some route endpoints may be administrative/neighbourhood names rather than boarding locations.
5. The source's route sequence may describe a one-way direction only.
6. The route directory is historical (January 2010); current operation must be checked against contemporary sources.
